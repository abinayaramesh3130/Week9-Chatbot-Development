
# HealthCareBot

## Domain
Healthcare

## Model
Ollama - llama3.2:latest

## Features
- Answers general healthcare questions
- Includes 22 sample questions
- Saves conversation history
- Logs chatbot activity
- Stores AI responses in CSV format

## How to Run
1. Install Ollama.
2. Make sure the llama3.2:latest model is available.
3. Run: python healthcare_chatbot.py

## Safety
This chatbot provides educational health information only. It does not diagnose diseases or prescribe medicines. Consult a qualified healthcare professional for medical advice.
